# UMN Lambda Phi Epsilon Website

A modern Vercel-ready React/Vite redesign for Lambda Phi Epsilon at the University of Minnesota.

## Run locally
```bash
npm install
npm run dev
```

## Deploy to Vercel
- Push this folder to GitHub
- Import the repo into Vercel
- Framework: Vite
- Build command: `npm run build`
- Output directory: `dist`

## Update content
Edit `src/App.jsx` to update chapter information, links, contact information, and rush details.
